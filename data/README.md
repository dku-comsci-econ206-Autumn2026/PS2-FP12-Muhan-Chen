# Human sessions

Seven completed sessions from the Hugging Face game. Each file is one pair. Session code 206. Twelve rounds. A round is valid when both the Promiser and the Decider locked a choice. All 84 rounds meet that rule.

These files are human play. They are not the interface test. The blank columns at the end of each file are unused.

`session-01.csv` through `session-07.csv`.
